# Startup Company Website - NovaTech

A professional startup company webpage built with HTML, CSS, and JavaScript.

## Project Description
This website includes:
- Hero / Company introduction
- About section with stats
- Products & Services
- Team members
- Achievements
- Client Testimonials
- Contact form

## Features
- Fully responsive (works on mobile & desktop)
- Modern purple gradient theme
- Smooth animations
- Mobile hamburger menu
- Clean professional design

## Technologies Used
- HTML5
- CSS3 (Flexbox + Grid + Animations)
- Vanilla JavaScript
- Font Awesome Icons

## How to Run
1. Open `index.html` in any modern browser
2. Deploy using GitHub Pages, Netlify, or Vercel
